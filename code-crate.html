12-Course Multi-Track Curriculum

Structured 12-course catalog across 4 distinct learning tracks: Core Programming (Python, C++, Java), Web Dev (HTML, CSS, JS, TS, Tailwind), Frameworks (React, Next.js), and Graphic Design (Photoshop, Illustrator) with custom SVG emblems.

AOS Motion & Floating Scroll Controls

Viewport scroll orchestration powered by the AOS (Animate On Scroll) engine (1500ms fade-up), combined with scroll-position listeners dynamically toggling floating buttons for smooth bidirectional page navigation.
