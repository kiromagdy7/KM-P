TravelyBooking Platform (Demo)

A full-stack travel agency and hotel reservation platform built with .NET 9.0 and ASP.NET Core MVC. Features dynamic hotel room availability, automated night stay calculations, secure Stripe payment gateway integration, claims-based cookie authentication with BCrypt hashing, customer wishlists, in-app notifications, and comprehensive back-office management across 12 controllers and 46 CSHTML views.

ASP.NET Core MVC (.NET 9) C# Entity Framework Core 9 SQL Server (12 DbSets) Stripe.net (v50) BCrypt.Net-Next Cookie Auth (Claims) Bootstrap 5 & AOS

Engineering Highlights.

[01]

Hotel & Room Booking Engine

Multi-hotel catalog with amenities filtering (Wi-Fi, Pool, Spa, Gym, Restaurant) and dynamic room availability management. Calculates stay duration, nightly rates, and total checkout prices via HotelService and BookingService.

EF Core 9 / Hotel & Booking Services
[02]

Stripe Payment Gateway Integration

Full credit card checkout pipeline using Stripe.net SessionService to create encrypted checkout sessions, track transaction lifecycle, update booking status upon verification, and issue printable payment receipts.

Stripe.net v50 / Online Checkout
[03]

Claims Cookie Auth & BCrypt Security

Secure claims-based cookie authentication scheme (Travely.Auth, 24h lifetime) paired with BCrypt.Net-Next salted hashing, role-based authorization (Customer, Staff, Admin), and custom [ProfileImage] validation.

Cookie Auth / BCrypt.Net-Next
[04]

Admin & Staff Operations Portal

Centralized management back-office across 12 controllers allowing administrators and staff to manage hotel listings, room inventories, booking states (Pending, Confirmed, Cancelled), user roles, and financial records.

12 Controllers / Role-Based Operations
[05]

User Accounts, Wishlist & Notifications

Dedicated customer portal with profile customization, photo upload via FileSystemImageStorage, booking history tracking (MyBookings), hotel wishlist bookmarking, and targeted in-app notifications.

User Portal / Wishlist & Notifications
[06]

Modern Responsive UI & Client Stack

Server-rendered Razor Views paired with Bootstrap 5, Swiper carousels for room galleries, GLightbox modals, Isotope dynamic card filtering, and jQuery unobtrusive client-side validation.

Razor Views / Swiper / Isotope
