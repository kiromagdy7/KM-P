KMZ HubPlayStation Center Platform

An offline-first Windows desktop platform (.NET 10 MAUI Blazor Hybrid) purpose-built for PlayStation gaming centers and cafes. Operates with local SQLite storage across 16 DbSets, concurrent multi-rate session stopwatches with quarter-hour rounding algorithms, cafeteria POS with live inventory tracking, shift drawer audit controls, direct receipt printing via dedicated STA threads, and PBKDF2 password security.

Engineering Highlights.

[01]

Multi-Rate Session Timers & Quarter-Hour Calculator

Independent precision stopwatches per PlayStation device, supporting dynamic Single and Multiplayer rate transitions in real-time. Employs a specialized mathematical rounding algorithm: first 15 minutes free, followed by 15-minute segments (<10 mins rounds down, ≥10 mins rounds up to next quarter-hour).

C# Precision Timers / SessionCalculator
[02]

Direct 80mm ESC/POS Thermal Printing (STA Thread)

Low-level receipt rendering pipeline utilizing System.Drawing.Printing.PrintDocument. Generates itemized receipt layouts (shop header, logo, session duration breakdown, cafeteria orders, and cashier signature) directed to default 80mm printers on an isolated STA thread to prevent UI freezing.

System.Drawing.Printing / 80mm STA Pipe
[03]

Offline-First Local SQLite Architecture (16 DbSets)

Self-contained local desktop data layer stored at %LocalAppData%\KMZ_Hub_app.db. Managed by Entity Framework Core 10.0.3 across 16 relational DbSets, coupled with an automated DatabaseInitializerService that auto-creates the schema, applies migrations, and seeds default administrators on first launch.

SQLite / EF Core 10.0.3 (16 DbSets)
[04]

Integrated Cafeteria POS & Stock Control

Dual-mode point-of-sale terminal supporting direct walk-in sales (DirectSales) and open session billing (SessionProducts). Features real-time stock deduction, product cost analysis, margin tracking, and low-stock replenishment threshold warnings.

POS Terminal / Real-Time Inventory
[05]

Shift Control & Mandatory Cash Reconciliation

Strict financial shift auditing with opening balance logging, live transaction tracking (income and expenses), and mandatory end-of-shift cash drawer reconciliation comparing actual cash against software totals before cashier sign-off.

Financial Shift Audit / Cash Drawer Handover
[06]

PBKDF2 Cryptography & Soft-Delete Recycle Bin

Enterprise-grade user authentication leveraging Microsoft KeyDerivation PBKDF2 with HMAC-SHA256 (10,000 iterations, 16-byte random salt). Features non-destructive soft-delete data protection (IsDeleted = true) paired with a RecycleBin.razor recovery console.

PBKDF2 HMAC-SHA256 / Soft-Delete Recovery
