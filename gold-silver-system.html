// ERP

Gold &
Silver System

Web Application

An ERP system purpose-built for gold and silver jewelry businesses. Built to handle the industry’s unique weight-based pricing, inventory, customer and supplier transactions, and dual-balance accounting. Supports multi-branch operations, payments, safes, refunds, coupons, user permissions, real-time notifications, audit logs, Arabic/English invoices, label printing workflows, and detailed business reporting.
