Jewelry SystemERP Platform

An enterprise-grade ERP built with .NET 10 and ASP.NET Core MVC, purpose-built for jewelry manufacturers and precious metal retail chains. Features a DynamicExpresso runtime pricing formula engine, dual-currency supplier accounting (EGP + grams), multi-branch weight-based stock control, QuestPDF Arabic RTL invoice generation, custom RFC 6238 TOTP 2FA, and 130+ granular permissions.

Engineering Highlights.

[01]

Dynamic Formula Pricing Engine

Runtime mathematical evaluation engine powered by DynamicExpresso.Core to calculate fluctuating karat spot rates. Resolves dynamic variables (WEIGHT, ItemPriceEx, OldFees, MAT[id].Price, TAX.Formula) with custom regex pattern matching.

DynamicExpresso / Runtime Formulas
[02]

Dual-Currency Supplier Accounting

Specialized double-entry ledger system (SupplierAccountLedger) simultaneously tracking financial obligations in Egyptian Pounds alongside raw metal weight in grams, featuring SupplierTransfer cross-material conversions.

Double-Entry / EGP + Grams Ledger
[03]

Multi-Location Stock & 13 Tx Types

Granular stock tracking across branches and safe vaults, managing quantities and decimal gram weights. Enforces 13 distinct transaction types (SALE, PURCHASE, KASR_MERGE, TRANSFER) with fast tray barcode auditing.

13 StockTxTypes / FastStockChecker
[04]

QuestPDF Arabic RTL Invoices & Labels

Vector PDF pipeline via QuestPDF 2026 with native Arabic RTL text layout, A4/A5 formats, dynamic social QR codes, ClosedXML Excel analytics, and 2-up dual-column CSV exports for BarTender jewelry string tags.

QuestPDF RTL / BarTender 2-Up CSV
[05]

Custom RFC 6238 TOTP 2FA & RBAC

Bespoke Two-Factor Authentication built from scratch following RFC 6238 (HMAC-SHA1, Base32 decoding, ±1 window) for Google Authenticator, coupled with 130+ seeded granular permissions enforced via [RequirePermission] and tag helpers.

Custom TOTP (RFC 6238) / Custom RBAC
[06]

EF Core Interceptor Auditing & SignalR

AuditSaveChangesInterceptor capturing field-level changes with a 15-second merge window to coalesce rapid edits and mask sensitive credentials, alongside real-time user notifications powered by SignalR NotificationHub.

EF Core Interceptors / SignalR
