IP Inspector

Web Application

A real-time IP intelligence tool that instantly reveals your public IPv4 address alongside live connection metrics including network type, speed, and latency. Supports full geolocation lookup for any IP address — displaying country, city, region, ISP, AS number, timezone, and coordinates — powered by an interactive Leaflet map. Features include one-click IPv4 copy, full JSON export, and clean TXT/JSON data export. Built with a clean responsive UI supporting both light and dark mode.
