Engineering Highlights.

[01]

Dual-API IP Resolution & Geolocation Pipeline

Asynchronously queries api.ipify.org for instant IPv4 detection followed by ipapi.co for in-depth geolocation metadata (country, city, region, ISP, AS number, timezone, coordinates) wrapped in an AbortController with an 8-second network timeout.

Fetch API / AbortController / REST APIs
[02]

Interactive Leaflet.js Mapping & Theme-Aware CartoDB Tiles

Renders dynamic geographic positioning at Zoom 12 using Leaflet.js 1.9.4. Seamlessly swaps vector tile layers on the fly between CartoDB Dark (dark_all) and Light (light_all) when switching color schemes.

Leaflet.js 1.9.4 / CartoDB / Dynamic Tiles
[03]

Live Hardware & Network Telemetry Metrics

Interrogates the browser navigator.connection API to display real-time connection status pills: network type (4G, WiFi, Ethernet), downlink speed in Mbps, and round-trip time (RTT/latency in ms) alongside VPN/proxy warning detection.

navigator.connection / Network Telemetry
