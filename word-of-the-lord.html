Word of the LordSpiritual Platform

A digital Coptic Orthodox platform built with Vanilla JavaScript and local JSON datasets. Features a dynamic random verse of the day, an interactive 9-book scripture reader, hour-by-hour Agpeya canonical prayers, detailed exposition of the 7 Church Sacraments, and a curated YouTube sermons directory.

HTML5 / CSS3 Vanilla JavaScript Fetch API & Local JSON

Engineering Highlights.

[01]

Dynamic 9-Book Scripture Reader

Three-tier cascading dropdown architecture (Book, Chapter, Verse) fetching structured local JSON across 5 Old Testament books and 4 New Testament Gospels with full chapter and verse rendering.

Cascading Dropdowns & JSON
[02]

Agpeya Canonical Hours Engine

Interactive prayer selector across 9 Coptic canonical hours, dynamically fetching JSON prayer datasets to populate navigable sub-sections (Psalms, Gospel passages, and liturgical absolutions).

Asynchronous Prayer Loader
[03]

Sacraments & Curated Sermons Directory

Comprehensive doctrinal expositions for all 7 Church Sacraments with dedicated artwork, paired with an 8-speaker directory linking directly to curated Coptic sermons on YouTube.

Liturgical Texts & Video Directory

Core Architecture

Media & External
