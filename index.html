ABOUT

Full-stack .NET developer based in Alexandria, focused on systems that hold up in daily use.

My day-to-day spans C# and ASP.NET Core on the backend, SQL Server and Entity Framework for data, and React, Next.js, WPF and .NET MAUI on the front end.
